# Zandvoort – komplett hemsida

## Ladda upp på GitHub Pages
1. Packa upp ZIP-filen.
2. Lägg index.html, övriga HTML-filer, styles.css, script.js och assets-mappen direkt i den mapp GitHub Pages publicerar. Behåll filnamn och mappstruktur.
3. Välj rätt publiceringsgren under Settings → Pages. Alla sid- och bildlänkar är relativa och fungerar även i en projektmapp.

Ingen installation eller kompilering behövs. Öppna index.html lokalt för en enkel förhandsvisning. Kopiera-funktionen fungerar bäst via HTTPS.

## Innehåll
Sex sidor: startsida, kollektion, inredningshjälp, om Zandvoort, besök/kontakt och integritet. Samtliga fotografier och typsnitt för sidans innehåll finns lokalt i assets. Officiell original-OG-bild behålls med sin befintliga adress på zandvoort.se.

Heron visar miljöer från samma Brafab-serier som förekommer på Zandvoorts officiella hemsida. Produktbilderna kommer från deras nuvarande hemsida. Den invändiga soffmiljön kommer från företagets eget offentliga LinkedIn-inlägg. Bilderna presenteras inte som namngivna kundprojekt. Inga nya AI-bilder eller påhittade porträtt har använts.

Originalbilderna i kollektionen är500×700px. Herobilden är1500×1125px och har inte skalats upp; större original kan ersätta den om kunden tillhandahåller dem.

## Kontakt och butik
Kontaktformuläret och produktförfrågningar öppnar ett mejlutkast. Besökaren skickar själv mejlet. Ingen server tar emot formulärdata, och ingen bokning eller beställning registreras på hemsidan.

Nuvarande webbutik uppges vara under ombyggnad. Denna leverans innehåller därför ingen betalning, varukorg, lagerkoppling eller orderhantering. Besökare hänvisas till butiken och direkt kontakt.

## Ändra information
Redigera texten direkt i respektive HTML-fil. Ändras produktinformation, uppdatera både bildkort och product-data i de sidor där produkten förekommer. Typsnittets licens finns i assets/fonts/OFL.txt.

Före publicering på egen domän: byt adressen https://zandvoort-inredning-nacka.carlzzon121.chatgpt.site i canonical, Open Graph URL, strukturerade data, sitemap.xml och robots.txt till den domän som ska användas.

Kontrollera öppettider och omdömesbetyg när de ändras. Det visade Houzz-betyget är daterat2oktober2026 och länkar till källan; det är ingen automatiskt uppdaterad widget.
